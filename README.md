# Whack-a-TopRock

Personalised birthday whack-a-mole gift. Phaser 3 + TypeScript + Vite.

## Run

```bash
cd C:\Users\user\Documents\whack-a-name
npm install
npm run dev
```

Open the local URL (default `http://localhost:5173`).

## Personalise

Edit `src/config.ts`:

- `PERSON.name`, `bannerTitle`, `endMessage`, roast lines
- Swap face PNGs in `public/assets/faces/`
- Hole layout in `HOLES` if the backdrop art changes

## Art

Fairground stall kit in `public/assets/art/` (ChatGPT Desktop peer art agent). Face cutouts from TopRock photos in Downloads (`Face_Pop_8_Separate_PNGs`).
